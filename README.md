# 书海拾贝 · 电子书宝库

线上打开：[书海拾贝 · 电子书宝库](https://www.embassygrade.com/)

欢迎来到书海拾贝 · 电子书宝库，一个可以按分类查找电子书的地方。英文名是 Ebook Vault。无论你是喜欢阅读经典文学、历史社会、经管励志、科普技术、职场学习，还是教材和论文，这里都能查到。

本库目前收录 35,895 条书目，涵盖中国古典与现当代文学、世界文学、历史与社会、人文社科、经济管理、科技科普、心理励志、悬疑推理、科幻奇幻，以及教材教辅、精选论文和编程文档。

## 简介

书目按分类整理。搜索、筛选和排序都在浏览器里完成。界面默认简体中文，可以换成 English，也可以在浅色和深色之间切换。不需要账号，也没有后台。
